Unity Nodes runs public snapshot servers for GenLayer testnet chains. These snapshots let you bootstrap a stuck or fresh validator node in **~5 minutes** instead of a multi-day full re-sync.

## What's inside a snapshot

Every snapshot contains **only** the public chain-state database (`genlayer.db/`) — the same PebbleDB LSM-tree files any synced node produces locally.

**Not included** (and never will be):
- No `keystore/`, private keys, or wallet material
- No `.env`, API tokens, or LLM provider credentials
- No node logs or hostnames
- No operator identity, IP addresses, or peer info

Snapshots are byte-equivalent to what your own node would produce after fully syncing from genesis. You are simply skipping the wait.

## Verification

Every snapshot is accompanied by a `.sha256` checksum file. Always verify before restoring:

```bash
curl -fLO https://snapshots.unitynodes.com/bradbury/latest.tar.gz
curl -fLO https://snapshots.unitynodes.com/bradbury/latest.tar.gz.sha256
sha256sum -c latest.tar.gz.sha256
```

## Rotation policy

- New snapshot every **6 hours** (00:00 / 06:00 / 12:00 / 18:00 UTC)
- Last **4** snapshots retained per network (24-hour coverage window)
- `latest.tar.gz` symlink always points to the newest one
- Older snapshots pruned automatically
